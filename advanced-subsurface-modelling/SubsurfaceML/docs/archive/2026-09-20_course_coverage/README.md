# Archive: course-topic coverage record of the 2026-09-20 version

These files document how the version published on 2026-09-20 mapped its
machine-learning components onto the topics of the supplied *Data Science and
Machine Learning* notebooks (41 of 42 topics, with a frozen topic inventory
and SHA-256 hash), and the completion report of that version.

They are kept for transparency and for the course attribution, but they are
**not part of the current study** and are **not regenerated**:

* the October 2026 revision is organised around one research question
  (`README.md`, `docs/TECHNICAL_REPORT.md`), not around topic coverage, as the
  portfolio review recommended;
* `build_coverage.py` checks evidence keys of the 2026-09-20 `summary.json`
  layout and the "learned" statements quote the 2026-09-20 demo run; both
  are out of date for the current results.

| File | What it is |
|---|---|
| `COVERAGE_MATRIX.md` | the generated topic-coverage table (2026-09-20) |
| `coverage/ml_topics.yaml`, `coverage/evidence.yaml`, `coverage/FROZEN_TOPICS.sha256` | the frozen topic inventory, the claimed evidence and its hash |
| `coverage_demo.json`, `coverage_study.json` | the machine-readable coverage results of the two 2026-09-20 runs |
| `build_coverage.py` | the script that produced them (runs only against the 2026-09-20 results layout) |
| `COMPLETION_REPORT.md` | the completion report of the 2026-09-20 corrections |
